# Varsity Lend website prototype

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Add `index.html` to the repository root.
3. Commit the file.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site and open the URL shown there.

## Before public launch
This is a front-end demonstration only. The enquiry form opens WhatsApp with a prefilled message; it does not store applications or process loans. Varsity Lend must approve all content and confirm current loan terms, eligibility, fees, privacy practices, legal business details and regulatory requirements before launch.
